# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussion about the work. Harassment
of any kind isn't acceptable, and maintainers may remove comments or contributors
that break these rules.

To report a problem privately, use
[private reporting](https://github.com/agenticlab-ai/pyxis/security/advisories/new)
or contact a maintainer on GitHub.
