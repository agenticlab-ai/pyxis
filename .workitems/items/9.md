**Plan:** implementation-verification — plan 001 (implementation-verification/001 · `docs/plans/implementation-verification/001-plan.md`) · **Design:** docs/tech-design/codegate-v1.md

## Goal

A fix cycle re-verifies without re-running the world and without ever laundering a stale result: the prior verdict is the sole state, and any doubt means a full run.

## Current behavior

Every invocation runs the full ladder; the loop pays the whole suite per fix.

## Desired behavior

`--incremental` reads the workspace's prior verdict; it qualifies only when every binding except the head revision matches (resolved diff base, manifest hash, baseline hash, codegate version, git version) and it parses — otherwise full run; the re-run set is the previously-failed rung first, plus every rung not recorded pass, plus every rung whose registry-declared input set changed under `git diff <prior head>`; only prior passes with unchanged inputs carry, marked `carried-from <run id>`; conservative v1 input defaults (whole tree for repo-verb rungs, the diff composition for rung 3) hold, with first-failure ordering as the stated primary economy.

## Scope

- Prior-verdict qualification with the full-binding match rule.
- Re-run-set computation from recorded results + input sets, and carried-pass marking.
- The invalidation fixtures: changed manifest, baseline, diff base, and codegate version each force a full run.

## Out of scope

- Sub-rung (per-test) caching — a future supersession by design.
- Any second state artifact — the verdict is the only state, structurally.

## Key interfaces

- `PlanIncremental(prior Verdict, bindings, diff) → RerunSet`; `CarriedPass{FromRunID}` in the verdict schema.

## Acceptance criteria

- [ ] A fixture fix-cycle re-verifies with strictly fewer verb runs than the initial full ladder, and its carried passes carry `carried-from` provenance.
- [ ] Changing any single binding (manifest, baseline, diff base, codegate version) forces a full run.
- [ ] A prior verdict containing a `skip:not-reached` or failed rung re-runs that rung — a pass-class verdict never emerges containing a never-run rung.
- [ ] A missing or unparseable prior verdict silently degrades to a full run (never an error).
