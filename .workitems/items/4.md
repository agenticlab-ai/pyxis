**Plan:** implementation-verification — plan 001 (implementation-verification/001 · `docs/plans/implementation-verification/001-plan.md`) · **Design:** docs/tech-design/codegate-v1.md

## Goal

The ladder runs end to end on a fixture repo: repo verbs execute env-stripped and time-bounded, a failing rung returns compact findings without executing later rungs, and the verdict enumerates everything.

## Current behavior

Invocations resolve and refuse correctly (T2) but no rung executes; no verdict has ever contained a real check result.

## Desired behavior

The runner executes a verb with an environment built only from the manifest's per-verb entries, kills it at its bound plus the recorded grace, and distinguishes spawn failure and timeout (rung error, exit 3) from check failure (red, exit 1); format/lint (rung 0), build (rung 1), and exec-probe (rung 4) checks run via the registry in latency order with first-failure stop; findings carry check id, class, rung, file:line where the class has one, a one-line message, and full output by reference in scratch; an unbound verb's check records `skip:verb-absent`, aggregates the rung as pass-with-skips, and drives green-degraded; unreached rungs record `skip:not-reached`.

## Scope

- The bounded runner: env construction (names + pinned values), wall-clock bound + grace, UB-1/UB-2 error classes.
- The four repo-verb check units and ladder execution with first-failure stop.
- Finding emission with log-by-reference scratch retention.
- The Go fixture repo driving red, green, green-degraded, and error paths.

## Out of scope

- The verbless neutral checks — T4.
- Write-scope enforcement (Landlock) — T9; this task ships strip + bounds only.

## Key interfaces

- `Runner.Exec(verb, bounds, env) → Result`; `Ladder.Run(bindings, mode) → Verdict`; the finding schema's field set (the joint feedback contract's v1 shape).

## Acceptance criteria

- [ ] A rung-0 lint failure returns findings with file:line and zero rung-1+ verb executions recorded; the probe-less fixture yields green-degraded with `skip:verb-absent` recorded.
- [ ] A fixture verb reading an ambient env var observes it absent; a pinned-value entry is observed; a hanging verb terminates at bound+grace with rung result error-timeout.
- [ ] A missing verb binary yields rung error class `infra` (exit 3), never red or green.
- [ ] Every completed run's verdict enumerates all configured rungs and checks, including `skip:not-reached` after an early stop.
