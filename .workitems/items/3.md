**Plan:** implementation-verification — plan 001 (implementation-verification/001 · `docs/plans/implementation-verification/001-plan.md`) · **Design:** docs/tech-design/codegate-v1.md

## Goal

`codegate run` implements the subprocess contract's edges: every invalid invocation refuses fail-closed before any verb executes, valid invocations resolve their bindings, and exactly one invocation holds a workspace at a time.

## Current behavior

T1's substrate exists but nothing is invocable; there is no binary entry point.

## Desired behavior

`codegate run --workspace --diff-base [--incremental]` refuses with exit 2 and a configuration-error verdict on any invalid, ambiguous, or flag-like-positional invocation, a missing or unparseable manifest, a malformed bound baseline, a dirty workspace (codegate scratch excepted), or a below-floor system git; the verdict is stdout-carried when the workspace flag itself is the defect, artifact-plus-stdout otherwise; a valid invocation resolves the six bindings (diff base resolved to a sha) and holds an flock-held descriptor — a concurrent invocation refuses busy; exit classes 0–3 are wired.

## Scope

- Invocation parsing with the full refusal matrix (I3 discipline) and exit-class wiring.
- Clean-tree assertion, git-version floor check, and bindings resolution.
- The configuration-error verdict emission rule (artifact vs stdout-carried).
- The flock workspace lock with busy refusal.

## Out of scope

- Running any rung — the ladder body is T3.
- Residue reaping and kill-recovery beyond the lock's kernel release — T9.

## Key interfaces

- `Invocation` (parsed contract), `Bindings` (the six-field set), `WorkspaceLock` (flock semantics); exit-class constants.

## Acceptance criteria

- [ ] Every malformed-invocation class (unknown mode, missing/ambiguous workspace or diff base, flag-like positional, dirty tree) refuses with exit 2 before any verb executes.
- [ ] The workspace-flag-defect fixture yields a stdout-carried configuration-error verdict; the malformed-manifest and malformed-baseline fixtures yield artifact verdicts naming the defect.
- [ ] A second concurrent invocation on the same workspace refuses busy while the first completes normally.
- [ ] A valid invocation's verdict records all six bindings with the diff base resolved to a sha.
