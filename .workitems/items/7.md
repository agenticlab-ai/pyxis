**Plan:** implementation-verification — plan 001 (implementation-verification/001 · `docs/plans/implementation-verification/001-plan.md`) · **Design:** docs/tech-design/codegate-v1.md

## Goal

Tautological tests are caught mechanically and legitimate diffs pass untouched: the falsification check proves new tests discriminate implementation presence, in a throwaway worktree the agent's tree never feels.

## Current behavior

Rung 3 does not exist; a test asserting nothing sails green (the basis's named top-risk class).

## Desired behavior

When the proposal diff's non-test half is non-empty and test files were added or modified, codegate creates a worktree at the workspace HEAD under a run-id-unique scratch path, provisions the manifest's declared state dirs, and runs two legs — sanity (unreverted: the targeted tests must pass, else rung error) then revert (reverse of the non-test half applied: tests passing without the implementation produce a falsification finding naming each) — focused where the stack's runner supports it; test-only or no-new-test diffs record not-applicable and emit nothing; a revert that does not apply is a rung error; the worktree is removed at run end and the workspace tree hash is byte-identical after every run.

## Scope

- The ephemeral-worktree lifecycle: run-id path, state-dir provisioning, removal.
- The two-leg protocol with the environment-vs-discrimination distinction.
- The FR-18 applicability rule and its not-applicable recording.
- The UB-4 inapplicable-revert error path.

## Out of scope

- The test-delta audit — T7 (a sibling check on the same rung).
- Stale-worktree pruning after kills — T9's janitor.

## Key interfaces

- `EphemeralWorktree{Create, Provision, Remove}`; `Falsify(diffset, worktree) → CheckResult` implementing the two-leg order.

## Acceptance criteria

- [ ] Catch seed 1 (a tautological test) reds rung 3 with a falsification finding naming the test.
- [ ] The refactor-only and mixed-with-genuine-tests fixtures pass without findings; the test-only fixture records falsification not-applicable while its test-delta audit still evaluates.
- [ ] A worktree whose sanity leg fails (a state-dir deliberately withheld) yields rung error — never a falsification verdict.
- [ ] After every rung-3 run — pass, red, or error — the workspace tree hash is byte-identical to before.
