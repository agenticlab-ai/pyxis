**Plan:** implementation-verification — plan 001 (implementation-verification/001 · `docs/plans/implementation-verification/001-plan.md`) · **Design:** docs/tech-design/codegate-v1.md

## Goal

The harness's data substrate exists and holds its invariants: a manifest that parses closed, a verdict that is atomic, revision-bound, and state-exclusive, and a registry that derives the ladder from self-registered checks.

## Current behavior

No verification code exists; `internal/verify` is empty ground.

## Desired behavior

The manifest schema parses closed (unknown keys are errors) with verb bindings, test globs, per-verb env entries (names passed or values pinned), time bounds, state dirs, and the baseline path; the verdict type carries per-rung and per-check results, findings, and the six bindings (head sha, resolved diff base, manifest hash, baseline hash, codegate version, git version), writes atomically, and enforces its state invariants; checks self-register with rung, verb dependencies, author-independence class, and input set; ecosystem defaults (globs, skip/assertion patterns, secret/artifact rules, failure-identity parsers, state-dir and cache-pin defaults) compile in as versioned data the manifest overrides.

## Scope

- The manifest, verdict, and finding types with closed parsing and the atomic temp+rename write.
- Property tests for the verdict invariants: bindings present, pass-class excludes fail/error and `skip:not-reached`, rung-and-check completeness.
- The check registry with per-file init() self-registration and ladder derivation.
- The compiled ecosystem-defaults tables with manifest-override resolution.

## Out of scope

- Any check logic or verb execution — later tasks register real checks.
- The CLI surface — T2's task.

## Key interfaces

- `Manifest`, `Verdict`, `RungResult`, `CheckResult`, `Finding` types; `Register(Check)` with `Check{Rung, VerbDeps, AuthorIndependent, InputSet}`; `ecosystem.Defaults(stack)`.

## Acceptance criteria

- [ ] A manifest with an unknown key fails closed-parse; a manifest declaring only a stack and a baseline path resolves the full verb set from ecosystem defaults.
- [ ] Property tests prove no verdict instance combines a pass-class state with any fail or error check result or a `skip:not-reached` rung.
- [ ] A demonstration check lands as one new file with zero shared-line edits, and the derived ladder includes it.
- [ ] An interrupted write (kill between temp and rename) leaves no verdict artifact.
