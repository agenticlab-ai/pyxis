# Requirement problems

Record each requirement problem found while designing or reviewing this
draft. A design-side session writes the next unused `P-n`, the affected
requirement ID, `Raised by`, and `Problem`; it does not edit `prd.md`.
For a missing requirement, reserve the new ID in the heading. Problem
numbers and requirement IDs are never reused across locked versions.

The product side records `Ruling` on that same problem before applying its
change to `prd.md`. The ruling names the author, reason, and exact change.
Only the operator, or Argus within a verified grant, may make that ruling.
A retirement removes the row; an addition uses the reserved ID. Keep the
problem and ruling in this draft as the change's provenance. Remove this
guidance when authoring.
